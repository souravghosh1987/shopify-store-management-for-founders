- [JSON templates](https://shopify.dev/docs/storefronts/themes/architecture/templates/json-templates): native section composition.
- [Agent Plugins specification](https://github.com/agentplugins/agent-plugins-spec/blob/main/spec/1.0.0.md) and [manifest schema](https://raw.githubusercontent.com/agentplugins/agent-plugins-spec/main/schemas/1.0.0/plugin.schema.json): portable package contract.
